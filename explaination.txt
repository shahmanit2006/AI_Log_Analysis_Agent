# Why SentenceTransformer?

SentenceTransformer converts text into dense vector embeddings.

Instead of comparing words directly, embeddings capture the semantic meaning of text.

This allows the system to retrieve relevant logs even if different words are used.

Model used:
all-MiniLM-L6-v2

Embedding Dimension:
384

# Why Embeddings?

Computers cannot understand natural language directly.

Embeddings convert every log entry into a numerical vector.

These vectors preserve the semantic meaning of the text.

Similar log messages generate similar vectors.

This enables semantic search instead of keyword matching.

# Why Qdrant?

Qdrant is a vector database.

Instead of storing only text, it stores:

- Embedding vector
- Original log
- Metadata

Qdrant performs similarity search using vector distance.

This allows the system to retrieve the most relevant logs quickly.

# Why Metadata?

Each log document contains metadata such as:

- File Name
- Log Level
- Log Type
- Date
- Time

Metadata provides additional information about each log.

Although similarity search uses embeddings, metadata helps explain where the retrieved log came from.

# Why Retrieval-Augmented Generation (RAG)?

Without RAG:

Question
↓

LLM

↓

May generate inaccurate or hallucinated answers.

With RAG:

Question
↓

Retrieve Relevant Logs

↓

LLM

↓

Evidence-based Answer

The retrieved logs provide context, making the AI response more accurate and reliable.

# Why Ollama?

Ollama allows running Large Language Models locally.

Advantages:

- No OpenAI API key required.
- Works offline.
- Better privacy.
- Faster experimentation.
- Suitable for educational projects.

# Why Conversation Mode?

Instead of asking one question and terminating the program,

the AI Agent keeps running until the user types:

exit

This provides a better user experience and avoids restarting the program for every query.

# Why Prompt Engineering?

The prompt instructs the LLM to:

- Use only the retrieved logs.
- Avoid hallucinations.
- Produce structured output.
- Explain the root cause.
- Provide recommendations.

A carefully designed prompt improves the quality and consistency of AI-generated responses.

# Why Cosine Similarity?

Cosine Similarity measures the similarity between two vectors.

Instead of comparing exact words, it compares semantic meaning.

Higher cosine similarity indicates that two pieces of text are more closely related.

Qdrant uses this similarity to retrieve the most relevant logs.

# Why Knowledge Base?

Instead of sending raw log files directly to the LLM,

all parsed logs are converted into structured documents.

These documents form the Knowledge Base used for semantic retrieval.

This improves retrieval efficiency and enables the RAG pipeline.
